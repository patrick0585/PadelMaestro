# iOS PR 2: Capacitor-Hülle – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein `ios/`-Projekt im Repo, das padelmaestro.de als iPhone-App lädt, mit Statusleiste, Icon, Splash und Offline-Seite, baubar per `pnpm cap:sync` und `xcodebuild`.

**Architecture:** Capacitor 8 im Remote-URL-Modus (`server.url = https://padelmaestro.de`). Ein winziger lokaler Web-Ordner `capacitor-web/` liefert nur die Offline-Seite (`server.errorPath`). Icons und Splash erzeugt das vorhandene Sharp-Skript aus `src/app/icon.svg`. Der Server-Deploy und die CI bleiben unberührt.

**Tech Stack:** Capacitor 8.6.0 mit Swift Package Manager, `@capacitor/status-bar` 8.0.4, `@capacitor/splash-screen` 8.0.2, Xcode 27.2, Node 22, Sharp, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-04-capacitor-shell-design.md`

## Global Constraints

- Exakte Versionen ohne `^`: `@capacitor/core` 8.6.0, `@capacitor/cli` 8.6.0, `@capacitor/ios` 8.6.0, `@capacitor/status-bar` 8.0.4, `@capacitor/splash-screen` 8.0.2.
- `capacitor.config.json`, nicht `.ts` (lädt unter Node 22 nicht).
- Bundle-ID `de.padelmaestro.app`, Anzeigename `Padelmaestro`, Version `1.0.0`, Build `1`.
- Nur iPhone (`TARGETED_DEVICE_FAMILY = 1`), nur Hochformat (`UIInterfaceOrientationPortrait`).
- `ios.appendUserAgent` exakt `PadelmaestroApp/1.0 (iOS)`.
- `server.url` `https://padelmaestro.de`; `server.allowNavigation` `["padelmaestro.de", "www.padelmaestro.de"]`.
- Hintergrundfarbe überall `#0b1220`.
- Kein Signing-Team im Repo; „Automatically manage signing" bleibt an.
- `deploy.sh`, `next build`, `.github/workflows/*` unverändert.
- Commits deutsch und kurz, ohne Tool-Hinweise.
- Tests: `set -a; . ./.env; set +a; node node_modules/vitest/vitest.mjs run <file>`; Typecheck `node node_modules/typescript/bin/tsc --noEmit -p tsconfig.json`.

## Review Focus

- **App-Store-Icon mit Alphakanal:** Apple lehnt ein 1024er-Icon mit Transparenz ab. Das Icon muss auf `#0b1220` geflacht sein. Test in Task 3.
- **Kein Netz beim Start:** Ohne Verbindung muss die Offline-Seite erscheinen statt einer leeren WebView, und „Erneut versuchen" muss `https://padelmaestro.de` laden. Test in Task 2, Prüfung in Task 4.
- **Splash hängt:** Erreicht die Seite den Splash-Aufruf nicht (Bridge fehlt, Seite lädt langsam), muss der native Fallback nach 3 s greifen. Config-Test in Task 1, Prüfung in Task 4.
- **Next-Build zieht `ios/` oder `capacitor-web/` ein:** Beide Ordner dürfen weder vom TypeScript-Check noch von Vitest erfasst werden. Prüfung in Task 1.
- **Lokale Build-Artefakte im Repo:** `xcuserdata`, `DerivedData`, `ios/App/App/public` und `capacitor.config.json`-Kopien dürfen nicht eingecheckt werden. Prüfung in Task 1.
